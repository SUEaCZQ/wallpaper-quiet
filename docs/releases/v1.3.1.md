## 留景 1.3.1

把桌面留给壁纸。空闲时渐隐桌面图标与任务栏，移动鼠标或按键即可恢复。

### 下载

- **普通用户**：下载 `WallpaperQuiet-1.3.1-Setup-x64.exe`。这是 Windows x64 安装包，内置 .NET 10 桌面运行环境，无需单独安装运行库。
- **查看或修改代码**：下载 `wallpaper-quiet-1.3.1-source.zip`，包含此版本源码、图标、两张演示 GIF 和构建脚本。
- **核对文件完整性**：使用 `SHA256SUMS.txt` 中的 SHA-256 校验值。

### 本次发布

- 首页重新编排：图标、项目名称、两张动态演示、下载入口和使用说明。
- 设置窗口保持打开时，仍可自动渐隐桌面图标和任务栏。
- 检查所有屏幕上的全屏、无边框全屏和最大化应用，后台被遮挡的应用同样触发保护。
- 安装时可选择桌面快捷方式和开机自启动。登录启动后收起到托盘并自动开启静享。
- 卸载清理属于该安装位置的登录任务，保留个人设置。

### 默认设置

空闲等待 **5 秒**，渐隐 **600 毫秒**，渐现 **250 毫秒**；桌面图标、任务栏、动态过渡均开启。「仅在桌面时运行」默认关闭，全屏与最大化保护始终生效。升级保留现有配置。

### 验证与说明

23 项桌面合成检查与 48 项 UI、启动、全屏判断检查通过；安装、自启动注册及卸载清理已实际验证。

源码 ZIP 从本版本的 Git 提交生成，排除了本机配置、日志、绝对用户路径、快捷方式、旧版本备份与构建缓存。两张 GIF 是项目作者提供的演示素材。

安装包目前未进行代码签名。主要在 Windows 11 与 Wallpaper Engine 环境验证，其他版本、HDR 及所有多屏组合尚未逐一实测。
